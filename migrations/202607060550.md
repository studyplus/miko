miko のスキル名が変わりました（Agent Skills 標準準拠のため、ドット区切りを廃止）。miko/ 配下のドキュメントに残る旧形式のスキル参照を新形式へ書き換えてください。対象がなければ何もせず終了してください。

## 変換規則

旧形式は `/miko.<名前>`（名前にドットやアンダースコアを含むことがある）。新形式は次の手順で得る:

1. `/miko.` に続く名前部分の `.` と `_` をすべて `-` に置き換える
2. プレフィックスをインストール形態に応じて付ける:
   - プロジェクトの `.claude/skills/` に `miko-` で始まるディレクトリが存在する場合（スクリプト版）: `/miko-<名前>`
   - それ以外（プラグイン版）: `/miko:<名前>`

変換例（スクリプト版 / プラグイン版）:

- `/miko.setup` → `/miko-setup` / `/miko:setup`
- `/miko.quick_impl` → `/miko-quick-impl` / `/miko:quick-impl`
- `/miko.speckit.plan` → `/miko-speckit-plan` / `/miko:speckit-plan`
- `/miko.catchup_system_hld` → `/miko-catchup-system-hld` / `/miko:catchup-system-hld`
- `/miko.miko` → `/miko-miko` / `/miko:miko`

## 手順

1. `.claude/skills/` 配下に `miko-` で始まるディレクトリがあるか確認し、プレフィックス（`/miko-` か `/miko:`）を決定する。

2. Grep で `miko/` 配下の `.md` ファイルから `/miko\.` を検索する。見つからなければ終了。

3. 該当する各ファイルについて、`/miko.<名前>` 形式のスキル参照をすべて変換規則に従って書き換える。スキル参照のみが対象で、それ以外の文章・パス表記は変更しない。

4. 書き換えたファイル数と置換箇所数を報告する。
