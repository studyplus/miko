`.miko/config` にスキル名の区切り文字設定（separator）を補完してください。

## 背景

v1.4.0 からスキル名の区切り文字（dot / hyphen）を選択できるようになり、選択が `.miko/config` の `separator=` に保存される。v1.4.0 より前のインストールにはこの設定がないため、既存の区切り文字であるドット（dot）を明示的に書き込む。

## 手順

以下のシェルスクリプトを Bash ツールでそのまま実行する。スクリプトを変更したり、これ以外の操作を行ったりしないこと。

```bash
if [ ! -f .miko/config ]; then
  # config がないのは言語選択導入（v1.1.0）前＝日本語版のみの時代のインストールなので language=ja とする
  mkdir -p .miko
  printf 'language=ja\nseparator=dot\n' > .miko/config
elif ! grep -q '^separator=' .miko/config; then
  echo 'separator=dot' >> .miko/config
fi
```
